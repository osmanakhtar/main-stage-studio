## What you can edit yourself

You have an Editor login. This means you can safely update content without
affecting the site's structure or design.

You can:
- Edit text on any page
- Swap images
- Add or update blog posts (if the site has a blog)
- Upload new media to the library

You cannot (and should not need to):
- Install or delete plugins
- Change theme settings
- Edit global styles or typography
- Access Bricks Builder settings

If you need something that's outside this scope, get in touch and we'll handle it.

## Editing a page

Your site is built in Bricks Builder. Here is how to edit any page:

1. In WP Admin, go to Pages in the left sidebar
2. Find the page you want to edit
3. Hover over it and click "Edit with Bricks"
4. The Bricks editor opens — the page appears on the right, elements on the left
5. Click on any text on the page to select it and edit it directly
6. Click on any image to swap it out
7. When done, click Save in the top toolbar
8. Click the eye icon to preview, or visit the live URL to see the published version

**One rule:** only edit text and images. Do not drag, move, delete, or add
elements unless you have been shown how to do this. Structural changes to layout
can affect the whole page.

## Swapping an image

1. Upload your new image first: Media, Add New, drag and drop your file
2. Recommended format: JPG for photos, PNG for logos or graphics with transparency
3. Recommended size: no wider than 2000px, under 500kb where possible
4. Open the page in Bricks (see above)
5. Click on the image you want to replace
6. In the left panel, click the image thumbnail and select your new image from
   the media library
7. Save

## Updating plugins

Plugins are the add-ons that power features on your site. They need updating
regularly for security and compatibility.

If MSS manages your site: we handle all plugin updates as part of the retainer.
You do not need to do anything.

If you manage your site yourself: check for updates monthly.
1. WP Admin, Dashboard, Updates
2. Review the list — select all plugins and click Update Plugins
3. Check the site after updating to confirm everything still works
4. Do not update Bricks Builder without checking the release notes first at
   bricksbuilder.io/changelog — major updates occasionally require adjustments

## If something looks broken

Before contacting us, check these things first:

1. Hard refresh the page: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)
2. Try a different browser
3. Try on a different device or network
4. Check if it affects one page or the whole site

Then contact us with: what you're seeing, which page, which device and browser,
and a screenshot if possible. The more detail you give, the faster we can fix it.

## A note on Bricks Builder

Bricks is a powerful page builder — more flexible than Squarespace or Wix, but
with a steeper learning curve. The edits described in this document (text, images)
are straightforward. Anything beyond that — new sections, layout changes, new
pages — is better handled by someone who knows the builder.

If you want to learn Bricks more deeply, the official documentation is at
bricksbuilder.io/docs and there is an active community at facebook.com/groups/bricksbuilder.
