Most tools should be thrown away.

Not because they failed. Because they did their job. A prototype that settles a layout argument. A script that checks every page for a claim you're not allowed to make. A mock onboarding flow that shows where clients drop out, before anyone writes production code.

Each of those used to cost a week. Now they cost an afternoon. That changes the question. It stops being "is this worth building?" and becomes "what do we need to know, and what's the fastest thing that tells us?"

We build a lot of tools we never intend to keep. What stays is the outcome: a decision made on evidence, a site that shipped right, a process that holds.

The tool was never the point.
